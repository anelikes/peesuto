# Development notes

Working from a checkout: the repository layout, the `paste` command line, how
text is measured and what the fixture digests cover. Setup, the engine rules
and commit conventions are in [CONTRIBUTING.md](../CONTRIBUTING.md); the
native app build is in [native/README.md](../native/README.md) (Chinese).

## Layout

```
core/        Core (Bun + TypeScript): the judgement — pick, actions, providers, render
  src/cli.ts       `paste`, the command line for the card chain
  src/daemon/      the long-lived sidecar the app talks to (JSON lines)
  src/pick/        smart paste: context levels, the pick question, the heuristic
  src/actions/     action format, loading, the built-ins, the runtime
  src/provider/    decider and generator tracks behind one egress layer
  src/catalog.ts   every name the decider may choose for a card, with the numbers behind it
  src/questions.ts the card's seven questions and answers → DSL
  src/render/      composition generation, emoji, engine driver, GIF/MP4
  src/templates/   local parsing, constrained selection, registry and template rendering
  fixtures/        five DSL fixtures and the digests they render to
native/      SwiftUI + AppKit desktop, system/storage/Core modules and tests
proxy/       a self-hostable Cloudflare Worker that forwards questions to Jev
site/        peesuto.com, generated by scripts/site.ts (docs/site.md)
docs/        formats, templates, releasing, the website
scripts/     engine setup, sidecar bundling, native build and release, probes
engine.json  the pinned Pocket Motion commit
```

## Models: two tracks

Both tracks are optional and self-hostable, and both go through one egress
layer with one offline switch and a log of where bytes went, never of what
they were.

- **Decider** — chooses the template, style and motion (never the words):
  local rules (the default), none, Jev through your own Cloudflare account,
  TypeSafe, Vercel AI Gateway or OpenRouter with your own key, any compatible
  endpoint including the proxy in `proxy/`, or a local model
  ([docs/laya.md](laya.md)). A fresh install decides cards by rules and picks
  history items by the heuristic, so it works with nothing configured and
  nothing leaving the machine.
- **Generator** — fills the prompt of a text action (translate, summarise,
  your own prompt): any OpenAI-compatible endpoint such as Ollama, vLLM or LM
  Studio, Anthropic, OpenRouter or Vercel, or none. Thinking models are
  handled as described in [docs/actions.md](actions.md#thinking-models).

What each provider sends and where is the table in the
[README](../README.md#what-leaves-the-machine) and in
[SECURITY.md](../SECURITY.md).

## The `paste` command line

Needs Bun 1.3.x and a prepared engine (`bun run setup`, or `POCKET_ENGINE`
pointing at a pocket-motion checkout; see CONTRIBUTING.md).

```bash
# no decision provider: a plain card, never wrong, never clever
bun run paste --provider none "本季度活跃用户增长了 37%，是过去三年最快的一次。"

# with Jev through the dev proxy (wrangler's own login, no key handled)
(cd proxy && npx wrangler dev --port 8787) &
bun run paste "本季度活跃用户增长了 37%，是过去三年最快的一次。" --aspect doc
pbpaste | bun run paste --stdin --aspect chat

# render a DSL as-is, skipping Jev
bun run paste --dsl core/fixtures/quote.json --out out/quote.gif
```

Output lands in `out/` unless `--out` says otherwise. `--json` prints one
JSON object with the path, the DSL and timings for CLI consumers. The desktop
normally uses the persistent [daemon protocol](daemon.md). Rendering happens
in a symlink tree under `.work/`; see the engine rules in CONTRIBUTING.md.

The CLI's explicit DSL fixtures continue to exercise the legacy card
renderer; their unchanged digests do not by themselves validate every
template family. `bun run studio` renders any text in every template, style,
motion and format for checking templates by eye.

## How a paste is measured

Text is measured against a cached metrics-only bake of
`core/src/render/charset.txt` (ASCII, CJK punctuation, GB2312 level 1), so a
paste costs one composition build, not two; a character outside the charset
falls back to a per-paste measurement build. Emoji are pictures: split out of
the text, fetched once from Noto Emoji at a pinned tag, staged beside the
composition and drawn inline at the font size, measured as one advance when
wrapping.

## Tests

```bash
bun test core/tests               # unit tests; the fixture renders skip without an engine
bun run typecheck
swift test --package-path native  # macOS native modules
```

`core/fixtures/digests.json` holds the SHA-256 of frames the five fixtures
render to at the pinned engine; a change there is either a deliberate
re-recording or a regression ([how to re-record](../CONTRIBUTING.md#digests)).
