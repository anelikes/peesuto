# Storyboard

Beat grid: 100 BPM, beat = 0.6 s, bars on beats 1, 5, 9 … (`music/timeline.json`).
All scenes live in `index.html` / `lib/scenes.js` on one timeline.

## Frame 1
status: built
src: lib/scenes.js#hook
time: 0–3.0 s (beats 0–5)
shape: custom glyph flight (rules: masked reveal, camera push-in)
Copied code sits selected in a notes window; ⌥V keycaps press on the first
downbeat; the window turns to the card's panel colour and the code is
highlighted in place; line by line the characters arc to the terminal card
(Indigo night field). "Copy text. / Paste a card." rises in masks.

## Frame 2
status: built
src: lib/scenes.js#pain
time: 3.0–7.8 s (beats 5–13)
shape: comparison-split
Left, "The usual way": screenshot crosshair, shutter flash, crop handles,
resize dialog, a small crooked paste, each on an off-beat with stepped easing.
"Four steps." Right, "With Peesuto": one ⌥V on beat 10, the real card. "One key."

## Frame 3
status: built
src: lib/scenes.js#showcase
time: 7.8–22.2 s (beats 13–37)
shape: spatial-pan-stations
"It reads what you copied." then six stations on one canvas: terminal,
chat, table, contact, Mermaid, release notes. Each raw text flies into its
card on the beat; the left side names the result. Pans get shorter
(0.62 → 0.46 s) and holds shorter (6 → 3 beats).
