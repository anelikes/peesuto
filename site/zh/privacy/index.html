隐私政策

更新于 2026 年 9 月 24 日

Peesuto 没有遥测，没有统计，也没有账号。除非你自己配置了 AI 服务，你复制的内容都留在你的 Mac 上。

存了什么，存在哪里

  • 剪贴板历史加密保存在你的 Mac 上，密钥存放在 macOS 钥匙串里。
  • 默认不记录：从密码管理器复制的内容，以及 macOS 标记为隐藏的内容（包括安全输入框）。
  • 生成的卡片保存在应用自己的文件夹里，超过 24 小时或超出最新 30 张的会被清理。
  • 你为 AI 服务填写的 API 密钥保存在钥匙串里，从不写进设置文件。

你随时可以在设置里清空历史。

会发送什么，且只在你选择时

默认情况下，Peesuto 用本地规则做决定，不会把你文字的任何信息发到任何地方。如果你配置了服务，发送的内容和去向如下：

服务发送的内容发往
本地规则（默认）什么都不发—
经 TypeSafe、Vercel AI Gateway 或 OpenRouter 使用 Jev关于这段文字的简短结构化问题，以及脱敏后的文字该服务，使用你的密钥
经 Cloudflare 使用 Jev同上你自己的 Workers AI 账号
自定义端点或本地模型同上你设置的 URL
文字生成（翻译、摘要、你自己的提示词）填好内容并脱敏后的提示词你设置的 base URL，使用你的密钥

发送之前，内置规则会先去掉 API 密钥、私钥、JWT、Bearer 令牌、URL 里的凭证以及对密钥的赋值。你可以添加自己的规则，也可以只发送结构。模型只决定卡片的样子，卡片本身永远在你的 Mac 上渲染。二维码从不发往任何地方。

设置里的离线开关会关闭以上所有请求共用的唯一网络通道。日志只记录数据发往了哪里，从不记录内容。

其他网络请求

  • Emoji。Emoji 图片来自应用自带的一套。缺少的 emoji 会按码位从 jsDelivr CDN（Google 的 Noto Emoji）下载一次并缓存。这只会透露是哪个 emoji，不会透露你的文字。
  • 检查更新。Peesuto 每天请求一次 https://peesuto.com/appcast.xml，看看有没有新版本，只有你同意后才下载。请求里只有应用名和版本号（更新框架 Sparkle 的 User-Agent）；Sparkle 可选的系统信息上报没有开启，所以不会发送关于你 Mac 的任何信息。可以在“设置 › 通用”里关闭自动检查。

本网站

peesuto.com 是静态网站。不设置 Cookie，不运行任何追踪或统计，也不从其他域名加载任何东西；字体和图片都由本站提供。我们的托管商 Cloudflare 会为了提供网站和保障安全而处理请求（包括 IP 地址），并保留常规日志。

核实与联系
